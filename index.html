System notificationsChecking…

UniBalance has no server, so it cannot send notifications while it is closed. Reminders appear on Home while the app is open, and as system notifications if you allow them. A reminder that comes due while the app is closed shows up the next time you open it.

Currency

Changing the currency only changes the label shown next to your amounts. Nothing is converted, so 1,000 Toman becomes 1,000 of the new unit.

Backup

Export saves your courses, tasks, events, finance records and settings as a JSON file. Import replaces everything currently in the app.

Install and offline

Install on iPhone: open UniBalance in Safari, tap Share, choose Add to Home Screen, then open it from the new icon. Installing and offline use need the app to be hosted on HTTPS.

About your data

UniBalance stores everything on this device only. Clearing browser data or switching devices erases it, and nothing syncs automatically. Export a backup regularly.
